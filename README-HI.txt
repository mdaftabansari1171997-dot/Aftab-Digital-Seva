AFTAB DIGITAL SEVA — PWA STARTER (DEMO)

इस पैकेज में क्या है:
- मोबाइल-फ्रेंडली वेबसाइट का शुरुआती UI
- सेवा कार्ड: प्रिंट, स्कैन, टाइपिंग, आवेदन सहायता
- डेमो ऑर्डर फॉर्म
- PWA manifest और service worker का शुरुआती ढाँचा

महत्वपूर्ण सीमाएँ:
- यह लाइव/प्रोडक्शन पोर्टल नहीं है।
- OTP लॉगिन अभी लागू नहीं है।
- ऑर्डर सर्वर/डेटाबेस में सेव नहीं होते।
- दस्तावेज अपलोड, निजी स्टोरेज, वास्तविक भुगतान सत्यापन, रसीद नंबर,
  एडमिन लॉगिन, दैनिक हिसाब और Excel एक्सपोर्ट अभी लागू नहीं हैं।
- डेमो फॉर्म में आधार नंबर, बैंक विवरण या कोई संवेदनशील दस्तावेज न डालें।

PWA के लिए:
- HTTPS hosting आवश्यक है।
- service-worker.js को index.html में register करने के लिए अगला development step आवश्यक है।
- किसी वास्तविक ग्राहक का डेटा जोड़ने से पहले सुरक्षित backend/database, authentication,
  authorization, backups और privacy policy तैयार करें।

शून्य बजट के लिए सुझाव:
- पहले इस UI को टेस्ट/डेमो के रूप में देखें।
- फिर free-tier hosting/backend की मौजूदा शर्तें जाँचकर backend जोड़ें।
- OTP SMS, custom domain, file storage या transaction fees पर आगे खर्च आ सकता है।
- लाइव वेबसाइट पर लगाने से पहले अलग test project और backup रखें।
